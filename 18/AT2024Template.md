# 1. Введение
Данный документ описывает требования к программной системе учета и инвентаризации основных средств, которыми оснащены офисные помещения, сдаваемые в аренду. Система использует RFID-метки, чтобы определять, где находится каждая единица имущества, проводить проверки по кабинетам и считать остаточную стоимость с учетом амортизации.

## Цели
Цель документа — зафиксировать требования к системе учёта и инвентаризации офисного имущества, внедрение которой должно повысить точность сведений о местоположении и состоянии имущества за счёт:
- **RFID-идентификации** — каждая единица имущества помечается RFID-меткой с уникальным идентификатором.
- **Инвентаризации по помещениям** — сотрудник выбирает кабинет, считывает метки и получает фактический перечень имущества.
- **Учёта амортизации** — система хранит первоначальную стоимость и срок полезного использования, рассчитывает остаточную стоимость.
- **Формирования ведомостей** — по повреждённому или утраченному имуществу готовится отчёт для дальнейшего рассмотрения.

## Границы применения
Система автоматизирует учёт офисного имущества, сдаваемого в аренду вместе с помещениями. В область применения входят:
- **Регистрация имущества** — создание карточки основного средства и привязка RFID-метки.
- **Учёт помещений** — ведение списка кабинетов и связи имущества с помещениями.
- **Инвентаризация** — считывание меток в выбранном кабинете и сопоставление с учётными данными.
- **Просмотр местоположения** — отображение последнего известного помещения для каждой единицы имущества.
- **Учёт амортизации** — расчёт остаточной стоимости по первоначальной стоимости и сроку полезного использования.
- **Формирование ведомостей** — отчёт по повреждённому или утраченному имуществу.

В документ не входят:
- **Предотвращение перемещения имущества** — система не мешает арендаторам переносить мебель.
- **Физическая охрана помещений** — не является предметом системы.
- **Автоматическое определение виновника повреждения** — решение принимает уполномоченный сотрудник.
- **Бухгалтерский и налоговый учёт** — не является предметом системы.
- **Выбор конкретных моделей оборудования и СУБД** — навязываются только предметной областью.

## Термины и аббревиатуры

| Термин/Сокращение | Определение |
|-------------------|-------------|
| **СТПО** | Спецификация требований к программному обеспечению |
| **RFID** | Radio Frequency Identification — радиочастотная идентификация |
| **RFID-метка** | Радиочастотная метка с уникальным идентификатором, закреплённая на объекте |
| **RFID-считыватель** | Устройство для считывания идентификаторов RFID-меток |
| **Основное средство** | Учитываемая единица имущества: стол, кресло, диван, шкаф, принтер и т.п. |
| **Карточка основного средства** | Запись в системе с данными о конкретной единице имущества |
| **Помещение (кабинет)** | Офисное пространство с уникальным номером или идентификатором |
| **Инвентаризация** | Проверка фактического наличия имущества в помещении и фиксация результатов |
| **Расхождение** | Несовпадение найденного имущества с учётным списком помещения |
| **Первоначальная стоимость** | Стоимость приобретения основного средства при регистрации |
| **Срок полезного использования** | Период, в течение которого планируется использовать основное средство |
| **Амортизация** | Расчётное уменьшение стоимости основного средства за время использования |
| **Остаточная стоимость** | Первоначальная стоимость минус накопленная амортизация |
| **Ведомость** | Отчёт со сведениями об имуществе и его расчётной остаточной стоимостью |
| **Администратор** | Пользователь, управляющий учётными записями, справочниками и правами доступа |
| **Сотрудник инвентаризации** | Пользователь, проводящий считывание меток в помещениях |
| **Руководитель** | Пользователь, просматривающий отчёты и работающий с арендаторами |

# 2. Общее описание

Система предназначена для учёта офисного имущества и проверки его фактического местоположения. Пользователь - управляющая организация офисного центра, сдающая помещения вместе с мебелью и оборудованием.

### Интерфейсы системы
- **Источник данных об имуществе** — администратор; ввод учётных сведений вручную.
- **Источник данных о помещениях** — администратор; ведение справочника кабинетов.
- **Источник данных инвентаризации** — сотрудник инвентаризации; считывание меток на месте.

### Интерфейсы пользователя
- **Интерфейс администратора** — веб-панель для ведения реестра имущества, справочника помещений, параметров амортизации, учётных записей и прав доступа.
- **Интерфейс сотрудника инвентаризации** — приложение на переносном устройстве (handheld-компьютере) с поддержкой RFID-считывателя; выбор кабинета, считывание меток, просмотр результатов.
- **Интерфейс руководителя** — веб-интерфейс для просмотра отчётов о наличии, местоположении имущества и ведомостей.

### Интерфейсы аппаратных средств ЭВМ
- **RFID-считыватель** — считывание идентификаторов меток.
- **RFID-метки** — закрепляются на каждой единице имущества.
- **Переносное устройство** — handheld-компьютер для работы сотрудника инвентаризации.
- **Сервер приложений** — размещение системы и обработка данных.
- **Рабочие станции** — доступ к веб-интерфейсу администратора и руководителя.

- **Интерфейсы программного обеспечения**: платформа переносного устройства и хранилище данных об имуществе, помещениях, арендаторах и инвентаризациях. Конкретные технологии пока не выбраны.
- **Интерфейсы коммуникаций**: способ обмена данными между устройством и хранилищем с помощью Wi-Fi
- **Ограничения памяти**: подлежат выяснению.
- **Действия**: подлежат выяснению.

### Интерфейсы программного обеспечения
- **СУБД** — хранение данных об имуществе, помещениях, арендаторах и инвентаризациях.
- **Операционная система переносного устройства** — среда работы мобильного приложения.
- **Веб-браузер** — доступ к интерфейсам администратора и руководителя.

### Интерфейсы коммуникаций
- **Беспроводная сеть Wi-Fi** — основная среда связи с переносным устройством.
- **Сетевые протоколы** — базовый обмен данными.
- **Защищённые протоколы передачи данных** — защита обмена.

### Ограничения памяти
- **Переносное устройство** — объём оперативной и постоянной памяти ограничен.
- **Система** — должна обеспечивать работу в условиях ограниченных ресурсов мобильных устройств.
- **Серверная память** — требования уточняются на этапе проектирования.

### Действия
- **Нормальные и специальные действия пользователей** — регистрация имущества, выбор помещения, инвентаризация, просмотр результатов, формирование ведомостей.
- **Различные способы действий в организации пользователя** — операции, инициируемые администратором (ведение учёта) и сотрудником инвентаризации (считывание меток).
- **Периоды диалоговых действий** — сеансы работы администратора с веб-интерфейсом и сотрудника инвентаризации с переносным устройством; конкретные значения подлежат уточнению.
- **Функции поддержки обработки данных** — ведение журналов операций и результатов инвентаризаций; состав отчётности подлежит уточнению.
- **Действия резервного копирования и восстановления** — подлежат выяснению.
