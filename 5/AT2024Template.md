## Термины и аббревиатуры

### Термины

| Термин | Определение |
|--------|-------------|
| Автоматизированная система | Комплекс программных, информационных и технических средств, автоматизирующий приём, обработку и сопровождение заявок на ремонт оборудования. |
| Время обработки заказа | Интервал времени от момента регистрации заявки до закрытия заказа или завершения ремонта. |
| Договор | Соглашение между заказчиком и исполнителем, определяющее условия обслуживания и ремонта оборудования. |
| Заказ | Заявка, принятая в обработку после проверки наличия договора и регистрации в системе. |
| Заказ-наряд | Электронный документ, содержащий перечень работ, оценку сложности, материалы, запчасти и стоимость ремонта, предъявляемый заказчику для согласования. |
| Заказчик | Организация или лицо, заключившее договор с исполнителем и обращающееся для ремонта оборудования. |
| Закрытие заказа | Действие сотрудника, завершающее обработку заказа, в том числе при отказе заказчика от согласования заказ-наряда. |
| Запчасти | Комплектующие изделия, заменяемые при ремонте оборудования. |
| Заявка | Первичное обращение заказчика о неисправности оборудования, поступившее через сайт, телефон или электронную почту. |
| Исполнитель | Организация, выполняющая диагностику, оценку и ремонт оборудования по договору. |
| Мастер | Сотрудник исполнителя, выезжающий на площадку заказчика для диагностики, оценки ремонта и выполнения работ. |
| Материалы | Расходные материалы, необходимые для выполнения ремонта. |
| Неисправность | Состояние оборудования, при котором оно не выполняет или выполняет с ошибками свои функции. |
| Оборудование | Офисная техника заказчика, переданная для диагностики, оценки и ремонта. |
| Офисная техника | Организационная техника, включая компьютеры, ноутбуки, принтеры, МФУ, сканеры, мониторы и аналогичные устройства. |
| Оценка ремонта | Предварительное определение сложности ремонта, необходимых материалов, запчастей и стоимости работ. |
| Отказ в согласовании | Решение заказчика не принимать предложенный заказ-наряд, после которого заказ закрывается сотрудником. |
| Площадка заказчика | Помещение или территория заказчика, где находится оборудование и выполняется ремонт. |
| Пользователь | Лицо, взаимодействующее с системой: заказчик, мастер, сотрудник или администратор. |
| Приложение | Программное приложение, используемое мастером и заказчиком для ввода оценки, просмотра и согласования заказ-наряда. |
| Ремонт | Комплекс работ по восстановлению работоспособности оборудования. |
| Сайт | Веб-ресурс, через который заказчик может оставить заявку на ремонт. |
| Сложность ремонта | Характеристика трудоёмкости и технической сложности работ по восстановлению оборудования. |
| Согласование заказа | Подтверждение заказчиком условий заказ-наряда в приложении; после согласования мастер начинает работу на месте. |
| Сотрудник | Представитель исполнителя, обрабатывающий заявку и/или выполняющий выезд к заказчику. |
| Статус заказа | Текущее состояние заказа в процессе обработки (например, «новая», «в обработке», «ожидает согласования», «согласована», «закрыта»). |
| Телефонный звонок | Канал обращения заказчика для создания заявки на ремонт. |
| Уведомление | Сообщение системы о событии, связанном с заявкой, неисправностью или изменением статуса заказа. |
| Уведомление о неисправности | Сообщение, сигнализирующее о возникновении или наличии неисправности оборудования и требующее обработки. |
| Электронная почта | Канал обращения заказчика, позволяющий отправить заявку или уведомление о неисправности. |
